# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/nkgotcode/iec104/security/advisories/new) for this fork. Include the affected commit, feature configuration, impact and an isolated reproducer. Do not test against live installations or publish exploit details in an ordinary issue.

This fork is under development. No release currently has a production security-support guarantee. Review applicable security findings before deployment. Transport security alone does not provide application authorization or establish IEC 62351 conformance.
